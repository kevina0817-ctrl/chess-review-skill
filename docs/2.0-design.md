# Chess Review Open 2.0：设计说明

插件位于 `plugins/chess-review`，版本 `2.0.0`。包含 Codex manifest 和两个可分别识别的 Agent Skills：

- `chess-review-open`：连接公开用户名、按需取谱、单盘复盘与归档；保留旧 skill 名称。
- `chess-common-leaks`：至少 10 盘已完成复盘后可选开启，随后每盘增量更新。

## 共享实现

共享脚本、模板、规范和一份 Stockfish 保留在 `chess-review-open`。跨局入口通过相邻路径复用；完整安装两个 skill 即可，不复制引擎和棋局。`verified_review_info` 核对 PGN、身份、完整回放和已有教学数据；规划器与构建器均执行首次 10 盘门槛。后续一盘即可增量，旧档案保留。

Common leaks 默认展示漏洞标签，进步放独立标签。首次默认整理最近 10 盘已有分析，每盘都记录检查结果；新类别不凭一次出现标成多盘复现。用户关闭后保留历史，普通单盘复盘继续可用。

## 自动化边界

只连接账号时 `fetch_chesscom.py --connect-only` 校验公开用户名并保存本地设置。复盘请求才抓最新一盘或明确指定的数量；不需密码，不运行后台轮询。累计达到门槛只提示一次，可选开启；开启后跟随新复盘更新，无需重复口令。

## 耗时

默认先完成一盘，环境就绪后预估 2–6 分钟。10 盘已有复盘的首次归纳预估 8–20 分钟，预算 25 分钟、目标约半小时内。都不是性能保证。内置多平台引擎约 387 MB，首次安装依赖和下载另计；当前尚未改成按平台下载或后台 job。

## 仓库与交付

2.0 将 v1 的 `skills/chess-review-open` 移到 `plugins/chess-review/skills/chess-review-open`；脚本内部的相对资源路径不变。升级时一起安装两个相邻的 skill，保留完整资源目录。

发布前校验 Codex manifest 与两个 skill，使用虚构棋谱测试功能，并通过浏览器检查页面。其他代理可使用 Agent Skills 入口；Codex plugin manifest 只用于支持该格式的宿主。

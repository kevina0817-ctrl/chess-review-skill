# 3.0 功能与验收

目标：保留关键步教学的简洁页面，让使用者既看懂原因，也能通过数据、对手走法和开局知识学习。

| 用户反馈 | 3.0 交付 | 验收 |
|---|---|---|
| 想看对手的好棋与 blunder | 双方关键步、按我方/对手筛选；可代对手试走 | 每条标明执子方；不把对手失误算成自己的能力 |
| 喜欢数据、graph、总分 | 总览分数、双方对比、开局/中局/残局分项、评估曲线 | 从引擎数据算；展示样本数；没有样本不打分 |
| 黑白优劣势条 | 棋盘旁显示当前局面评估，随回放更新 | 正负固定白方视角；翻转棋盘不改符号；将杀与兵值分开 |
| 能给对手制造什么威胁 | 可回放引擎建议后续，标出将军、吃子和将死 | 与实际棋谱区分；建议分支未知评估显示未分析 |
| 提前理解危险 | 当前被将军、将杀信号、引擎主变化中的风险 | 不把一条合法示范说成对手必然会走或强制将杀证明 |
| 从实战学开局与阵型 | 离线开局库匹配实际局面，跳回对应步骤；学习链接和本盘计划 | 支持转置；不凭 PGN 标签或外形乱贴开局名；链接不内嵌视频、不自动联网 |

## 评分口径

第一版展示「走法质量参考分」，不是等级分、考试成绩、作弊判断，也不冒充 GTOW、Chess.com 或 Lichess 的整局准确率。单步映射参考 Lichess 公开公式，本插件采用各步算术平均；同时给出失误数、平均兵值损失、样本数量，解释单个大失误可能被平均数掩盖。

分项按开局/中局/残局划分，明确启发式分段规则。不存在的阶段显示「无样本」。暂不凭空给「创造力」「战术天赋」打分。当前不提供 GTOW 自定义维度或外部算分服务；后续扩展需要明确可核对的指标与接口。

## 交互与边界

- 总览用短数字卡片与一张可点击曲线；详细方法、开局学习折叠展示。
- 对手事件与威胁解释共用现有棋盘，避免再堆大量页面。
- 「实时」指跟随所回放局面更新的预计算评估，不在网页运行引擎，不辅助进行中的对局。
- 无引擎数据时保留原复盘，数字显示不可用；只对完全匹配的棋谱和局面展示分析。
- 输出仍是使用者本地 HTML/PGN，无自动发布；与 2.0 页面及笔记键兼容。
- 不接入外部算分服务，不新增后台任务；插件发布不改变用户复盘默认只输出本地文件的约定。

## 本地验收记录（2026-09-24）

以上六项已实现于 3.0。使用公开的 1858 年歌剧院棋局进行真实 Stockfish 分析，分别生成白方、黑方预览；虚构教学棋局验证无分析数据的兼容模式。

- 20 项 Python 测试通过，覆盖自动取谱、去重、跨局门槛、对手证据隔离、评分视角、终局、开局转置和输入一致性。
- 三种预览通过浏览器检查：曲线跳转、翻转棋盘、建议分支未分析状态、将杀回放、双方筛选及离线无外部请求。
- 原有执黑试走、笔记、PGN 下载和整盘回放检查通过；检查了桌面与 390 / 320 像素窄屏。
- 两个 skill 与 plugin 清单验证通过；README 已补 3.0 截图。发布包只包含通用脚本、模板、文档、测试与教学示例。

不在本版范围内：GTOW 自定义维度、外部算分服务，以及仅凭得分上涨就自动认定某个漏洞已修复。

# 3.1 功能与验收

双方卡片显示各自总手数、严重失误、失误和已确认好棋次数。取消准确率式总分、阶段分、单步评分及提示，避免平均数掩盖严重失误。

- 严重失误与失误互不重复。好棋只统计已核对并收录的 positive 实战 lesson，按真实执子方和 ply 去重；0 次表示暂未收录。
- 保留可点击的局面曲线和棋盘旁优劣势条，始终使用白方视角；翻转只改变位置。曲线不是准确率或真实胜率。
- 双方关键步、试走、引擎后续、将军与将死标记、开局识别和学习链接继续可用。
- 缺少匹配引擎数据时，完整统计和曲线明确不可用。未经独立分析的试走或建议分支显示未分析。
- 输出仍是本地单文件 HTML/PGN，保留笔记键、离线使用、档案与已开启的跨局增量流程。

## 验收方法

运行 `python -m unittest discover -s tests` 检查分析视角、计数、评分字段移除、终局、输入一致性、取谱和跨局规则。按运行说明用 `check_insights.cjs` 检查公开歌剧院棋局的白方、黑方和无引擎版本，验证曲线跳转、双方计数、示范变化、未知评估、离线行为与 390 / 320 像素布局；用 `check_review.cjs` 检查试走、笔记和 PGN 下载。

README 截图只使用公开历史棋局与虚构教学示例。默认不发布使用者棋谱；此次插件源码发布不改变该约定。统计口径详见 [分析说明](../plugins/chess-review/skills/chess-review-open/references/analytics.md)。
